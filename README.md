# Module-5-Data-Analysis-using-Python
Social Media Engagement Analytics Using Python
📌 Project Overview

This project analyzes 5,000 social media posts to identify patterns in user engagement, content performance, behavior, and sentiment.

🛠️ Tools & Libraries
Python
Pandas
NumPy
Matplotlib
Seaborn
Plotly
🔍 Analysis Performed
Data cleaning and preprocessing
Missing value and duplicate handling
Descriptive and statistical analysis
Content performance analysis
User and behavioral trend analysis
Sentiment analysis
Interactive data visualization
📊 Key Insights
Video posts showed high engagement.
Food was the best-performing content category.
Brazil recorded the highest average engagement rate.
Verified accounts showed slightly higher engagement.
Mobile users had the highest average watch time.
Negative-sentiment posts showed the highest average engagement.
Posting time could not be analyzed because the dataset contains dates but not actual posting times.
📁 Dataset

social_media_engagement_5000.csv – 5,000 social media records containing information about users, posts, engagement, devices, sentiment, and other attributes.

🎯 Conclusion

The project demonstrates how Python data analysis and visualization techniques can be used to discover meaningful insights from social media engagement data.
